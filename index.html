Core Stack

The three foundational projects that power the entire ecosystem.

Kernel

imx708-driver

Linux kernel driver for the Sony IMX708 camera sensor. Exposes V4L2 controls, HDR mode, exposure/gain tuning, and provides a C userspace library (libimx708) for application development.

C · Kernel Module
Service

imx708-server

C++17 gRPC daemon wrapping the IMX708 camera in an RAII Camera class. Provides streaming, capture, and control RPCs. Built with CMake + Ninja, tested with Catch2.

C++ · gRPC · CMake
Desktop

imx708-gui

Cross-platform PySide6 desktop GUI with macOS-inspired design. Real-time telemetry via gRPC streaming, full sensor control, and custom widgets. Packaged as a standalone executable.

Python · PySide6 · Qt

Application Layer

Python applications that build on the core stack for real-world vision tasks.

Core Stack

Three Foundations

The kernel driver, gRPC service layer, and desktop GUI that form the backbone of every application.

Kernel Module

imx708-driver

Linux kernel driver for the Sony IMX708 sensor. Exposes V4L2 controls, HDR mode, exposure/gain tuning, and provides a C userspace library (libimx708).

C · Linux Kernel
gRPC Service

imx708-server

C++17 gRPC daemon wrapping the IMX708 camera in an RAII Camera class. Streaming, capture, and control RPCs. Built with CMake + Ninja, tested with Catch2.

C++ · gRPC · CMake
Desktop Application

imx708-gui

Cross-platform PySide6 desktop GUI with macOS-inspired design. Real-time telemetry via gRPC streaming, full sensor control, custom widgets, standalone executable.

Python · PySide6 · Qt
